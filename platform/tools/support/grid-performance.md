# اصلاح کارایی گرید — محیط توسعه
ستون عملیات شامل دکمه جزئیات و بررسی کردم از گرید مشترک حذف شد. عنوان رکورد مسیر دسترسی به جزئیات باقی ماند. داده بررسی قبلی حذف نشد.
رمزگشایی تکراری مخزن و حساب مستقل با حافظه موقت مبتنی بر برابری کامل محتوای فایل کاهش یافت؛ فایل در هر بار خوانده می‌شود، تغییر فایل باعث بی‌اعتبارشدن حافظه می‌شود، خروجی کپی مستقل است و کنترل مالکیت/دسترسی حذف نشده است. مخزن حداکثر ۸ ورودی حافظه دارد؛ داده رمزگشایی‌شده روی دیسک نوشته نمی‌شود.
آزمون واقعی پاسخ API بکلاگ: قبل ۱۴۸۶، ۱۳۶۴، ۱۳۷۸ میلی‌ثانیه؛ بعد ۳۰۱، ۳۳۱، ۳۷۹، ۳۰۲ میلی‌ثانیه. این اندازه‌گیری زمان پاسخ سرور محلی است، نه زمان کامل نمایش مرورگر.
۱۸ آزمون HTTP/میزبان و یک آزمون حافظه موفق. آزمون حافظه تغییر فایل توسط نویسنده دیگر و جلوگیری از تغییر داده از طریق مقدار بازگشتی را پوشش می‌دهد. سرور توسعه فعال شد؛ نسخه تغییر نکرد.
