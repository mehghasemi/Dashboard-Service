# دستیار مدیر پشتیبانی

ریشهٔ پروژه در این رایانه: `D:\MyData\MyApp-AI\CodexAPP\Dashboard-Servcie`

- `platform/`: سورس نسخهٔ مستقل توسعه برای Windows.
- `server-extension/dashboard-service/`: سورس افزونهٔ آمادهٔ تحویل به میزکار Combine.
- `SERVER-DEPLOYMENT-FA.md`: راهنمای تحویل نسخهٔ سرور.
- `artifacts/`: بسته‌های ZIP، مبنای دریافتی و ابزارهای آماده‌سازی محلی. این پوشه در Git ثبت نمی‌شود.

نسخهٔ مستقل محلی از `artifacts/source-package/Start.cmd` اجرا می‌شود. نسخهٔ `0.1.0` افزونهٔ سرور در قالب بستهٔ قابل‌بارگذاری در میزکار آماده شده است؛ نصب نهایی روی سرور بعد از پذیرش در میزکار انجام می‌شود.
